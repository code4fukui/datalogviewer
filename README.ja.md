# datalogviewer

CSVファイル内の時系列データから、インタラクティブな2軸の折れ線グラフを生成するWebベースのビューワーです。ファイルをドラッグ＆ドロップするだけで簡単に可視化できます。

## ライブデモ

このビューワーは、以下のブログ記事のために作成されました：**[data log viewer for iOS App of Barometer](https://fukuno.jig.jp/4795)**

![datalogviewerのスクリーンショット。左Y軸に気圧、右Y軸に相対高度を表示し、時間軸をX軸とした2軸の折れ線グラフが描画されています。](https://fukuno.jig.jp/img/datalogviewer.png)

## 機能

-   **即座の可視化:** CSVファイルをドラッグ＆ドロップするだけで、自動的にチャートを生成します。
-   **複数データ系列のプロット:** CSVのすべての数値列を `timestamp` 列を基準にして自動的にプロットします。
-   **二重Y軸:** 2つのデータ列がある場合（例: 気圧と高度）、各データ系列に独立したY軸を割り当て、2軸チャートを描画します。
-   **ギャップ検出:** データ内の10秒を超える時間ギャップをスマートに検出し、折れ線グラフの途切れ（ブレーク）として表示します。
-   **インタラクティブなツールチップ:** データポイントにカーソルを合わせると、正確なタイムスタンプと値の情報が表示されます。
-   **スマートなスケーリング:** データに合わせてY軸の範囲を自動調整し、すっきりと読みやすい目盛りを使用します。

## 使い方

1.  リポジトリをクローンします:
    ```bash
    git clone https://github.com/code4fukui/datalogviewer.git
    ```
2.  `index.html` ファイルをWebブラウザで開きます。
3.  CSVファイルをページにドラッグ＆ドロップします。

デフォルトでは、サンプルの `Barolog-2025-09-10.csv` が読み込まれます。

### CSVファイル形式

CSVファイルには、以下の構造を持つヘッダー行を含める必要があります:

-   1つの列の名前を `timestamp` とし、ISO 8601形式の文字列（例: `2025-09-10T06:58:05Z`）を含める必要があります。
-   その他のすべての列には数値データを含める必要があります。

**例:**
```csv
timestamp,pressure_hPa,relative_altitude_m
2025-09-10T06:58:05Z,1010.2,0.000
2025-09-10T06:58:06Z,1010.2,-0.127
...
```
